
Food Ordering App UI Design

Project Overview

This project is a mobile food ordering application UI designed using Figma. It allows users to explore food items, view product details, and go through an ordering process.

Design Tool

Figma
Main Features

-Home screen

-Food menu and product listings

-Food product details

-Shopping cart

-Checkout and order confirmation

-Login and registration screens
